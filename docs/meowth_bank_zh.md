# 喵喵银行说明（服主向）

本文档解释喵喵银行（存款 + 信用借贷 + 喵喵支付）的资金模型、还款与制裁机制、额度计算、防刷设计，以及服主的全部配置项与运营工具。

## 一、喵喵银行是什么

给市场交易提供**信用支付能力**：玩家可以借未来的钱现在消费，为服务器注入资金流动性；同时是服主的运营杠杆——利率、额度、逾期制裁全部可配置。

三个功能围绕准备金池运转：

| 功能 | 入口 | 资金流 |
|---|---|---|
| 存款/取款（活期） | 喵喵银行「存款/取款」按钮 | 存款进准备金池按日计息；取款池出（含利息） |
| 应急贷款（喵喵的帮助） | 喵喵银行柜台主动借款 | 钱从池出进玩家钱包，玩家分期还 |
| 喵喵支付（消费贷） | 购买精灵/物品弹窗的「喵喵支付」按钮 | 准备金直接垫付给卖家，买家欠款分期还 |

借款与喵喵支付共享同一个信用额度池；存款独立于额度（不参与额度计算）。

**只想开纯存取银行**：总开关开 + 「喵喵的帮助」与「喵喵支付」两个开关关即可——借款被拦、喵喵支付按钮自动消失、存取照常。

## 二、资金模型：准备金池

- 准备金池是借贷资金的唯一进出口（`FinanceState` 记账，重启不丢）
- 借款/喵喵支付 → 钱从池子出（给玩家/卖家）；还款本金与利息 100% 回池
- **准备金允许为负**（= 服主负债，管理面板红色告警），服主不必预充
- 坏账冲销不动池子（借款时已出账，损失已体现在池子里）

## 三、活期存款

- 存款进**准备金池**（充盈池子，借贷资金更真实），按**日利率**计息（默认 0.0001 = 每天 0.01%，年化约 3.65%，可配）
- 利息 = 本金 × 日利率 × 完整天数；**查看/存取款时实时结算**（不足整天不计息），存取操作把已累积利息落账入本金
- 取款随时可提（含累计利息），金额回到钱包；物品货币模式背包满时差额挂待领取
- **利息从准备金池支出**：池子为负（服主负债）时照发，管理面板红色告警可见
- 存款不参与额度计算、没有攻击面（存的是玩家自己的钱）
- **总开关关闭时存款被拦、取款永远开放**（钱是玩家的不能卡）

### 存贷利率护栏（防「借钱存银行」套利）

贷款与存款存在理论套利：借出贷款存进银行吃利息，若利息差为正即可无限循环刷钱。护栏在配置**加载与保存**时自动钳制存款日利率，上界：

```
存款日利率上限 = min( 每期费率 × (期数+1) ÷ (14 × 期数) )   ← 遍历全部贷款方案取最小值
```

- 该上界保证：**任何**还款方式（按期自动划扣 / 提前结清 / 用自有资金还贷而贷款存满全程）下，存款利息收入 ≤ 贷款利息支出，套利无收益
- 超出即自动钳制 + 日志警告（服主能看到钳制前的配错值）；服主把贷款费率配成 0（免息贷款）时，存款日利率被同步钳到 0——免息借款与存款利息不能并存
- 默认值 0.0001 距默认方案上界（3 期方案 ≈ 0.000476）有约 4.8 倍余量，正常调参不会触顶

### 净存款门槛（防「借钱包装存款冲申请条件」）

紫金卡/黑金卡的「存款余额要求」按**净存款**判定：净存款 = 活期存款余额 − 未还欠款（不含已注销坏账）。玩家借 50 万存进银行，存款+50 万但欠款+50 万，净存款不变——借钱包装资产无法满足门槛。申请界面条件行显示的值即净存款，玩家一眼可知判定口径。

## 四、贷款与还款

- 每笔贷款分 **3/6/12 期**，**每 7 天一期**，到期日固定（借后第 7/14/21 天…，不会因提前还款顺延）
- 利息 = 剩余本金 × 日利率 × 距上次还款天数（日利率 = 每期费率 ÷ 7，创建时快照，改配置不影响存量贷款）
- 到期自动从玩家余额全额划扣当期应还，**保留保底余额**（`autoRepayMinBalance`）不扣空钱包；余额不足 → 逾期
- 玩家可随时主动还一期或提前结清（利息实算到当天）
- 每期到期前一天，玩家收到黄色还款提醒

## 五、逾期制裁三档

| 逾期天数 | 制裁 | 解除方式 |
|---|---|---|
| 到期未还 | 逾期状态：禁止新增借款/喵喵支付，红色通知 | 还清欠期自动恢复 |
| ≥ 7 天 | 市场手续费翻倍（付款方） | 逾期天数降回 7 以下 |
| ≥ 14 天 | 冻结市场交易（复用封禁系统，拦交易不拦取回） | 还钱自动解冻 |
| ≥ 30 天 | 注销为坏账：本金无法收回，交易保持冻结，OP 收到告警 | 服主干预（见第九节） |

- 还款后制裁实时重算：还一期逾期天数减 7 天，降档立即生效（解冻/取消翻倍）
- 坏账玩家的冻结是永久的，服主有两档干预：**只解封**（恢复交易，仍禁借）或**撤销坏账**（交易+借款全恢复）

## 六、额度机制（信用卡模型）

```
信用基础 = max(近30天买入成交额×0.5 + 历史累计成交额×0.1, 额度下限)
可用额度 = max(0, 信用基础 − 未还欠款全额)，再钳额度上限
```

- **欠多少扣多少**：借 200 剩 800，还清恢复——额度是「可借总额池」
- 交易额按**买入方**计算（借贷对应花钱的能力）；基于成交额自动适配服务器通胀水平
- 防刷三层（成交时快照判定，全部静默不计额）：
  1. 喵喵支付成交不计额；有未结清贷款时买入成交不计额（防借→买→额度涨→再借）
  2. 同对交易检测：窗口（默认 30 天）内同一买卖对达到上限笔数（默认 3）后，该对后续成交不计额——**窗口天数与笔数上限服主可配**
  3. 买卖双方同 IP（买家非 OP）→ 该笔计入额 ×0.9
- **额度增长冷却**（默认 24 小时，可配 0 关闭）：成交后冷却期内不计入额度——额度增长延后到账，封堵「组团对刷→现刷现借→套现跑路」的快进快出窗口
- **同 IP 欠款上限**（`ipDebtLimit`）：30 天内用过该 IP 的所有玩家未结清欠款总和 + 本次借款不得超过上限，防同 IP 多小号分散借款（OP 豁免；0 = 不限制）

## 七、卡片系统（喵·紫金卡 / 喵·黑金卡）

高额度凭证物品——持有者获得**固定借款额度**（与交易额公式无关）。额度绑定持有者状态而非物品，刷物品漏洞复制出的卡无效；卡片丢弃立即消失（防转手），持有者可花补发费在喵喵银行重新领取。

### 喵·紫金卡

- 额度 `purpleCardCreditLimit`（默认 100 万）；全服发放上限 `purpleCardCount`（默认 20，0 = 不限制）
- 获得：服主 `/market card give <玩家>` 发放；或开启自行申请后玩家在喵喵银行左侧紫卡图标申请（申请费进准备金池）
- 自行申请六项条件（均可配，0 = 不要求）：资产（现金余额）/ 消费金额（历史买入成交额）/ 额度（信用基础）/ **净存款**（活期存款 − 未还欠款，见第三节）/ 图鉴收集数 / 无逾期记录
- 手续费减免：市场手续费按 `purpleCardFeeDiscount` 减免（上架费/拍卖成交费/求购中介费全覆盖，与逾期翻倍叠加，默认关闭）
- 持卡豁免同 IP 欠款上限（小号不可能持卡：全服限量 + 六项门槛）

### 喵·黑金卡

- 比紫卡高一级：额度 `blackCardCreditLimit`（默认 500 万）；全服上限 `blackCardCount`（默认 5）
- 申请硬条件：**必须已持有紫卡** + 六项条件（与紫卡同构可配）+ 申请费
- **升级替代**：获得黑卡自动移除紫卡资格（不占两个名额），额度与手续费减免按黑卡算
- 其余机制与紫卡相同（丢弃即消失 / 补发收费 / 持卡 IP 豁免）

### 服主工具

- `/market card give|revoke|list <玩家> [purple|black]`：发放/收回/查看（缺省紫卡；revoke 支持离线玩家）
- 卡片管理界面（喵喵银行规则按钮下方，仅 OP）：全部持有者列表 + 行尾一键收回
- 持有者展示面板（喵喵银行两卡下方，所有玩家可见）：标题显示持有人数/上限，面板内名单（皮肤头像 + 名字，可滚动）

## 八、配置项（游戏内服务器配置界面可直接编辑）

| 配置 | 默认 | 说明与建议 |
|---|---|---|
| `finance.enabled` | **关** | 总开关。借贷影响经济安全，服主显式开启才生效；关闭时禁止新增借贷/喵喵支付，已有贷款状态机照常运行（还款/逾期/坏账不受影响） |
| `cashLoanEnabled` | 开 | 现金贷（喵喵的帮助）开关 |
| `consumerLoanEnabled` | 开 | 消费贷（喵喵支付）开关；关闭时购买弹窗自动收缩、不显示按钮 |
| `loanPlans` | 3/6/12 期，费率 0.5%/0.8%/1.2% | 分期方案数组（期数+每期费率，每期 7 天）；改配置只影响新贷款 |
| 额度系数·近30天交易额 | 0.5 | 额度公式权重（见第六节） |
| 额度系数·历史交易额 | 0.1 | 额度公式权重 |
| 额度下限 / 上限 | 0 / 100000 | 下限只保底「无欠款」玩家（冷启动）；有欠款时额度走纯公式 |
| `autoRepayMinBalance` | 1000 | 自动划扣最低保留余额（划扣后余额不低于此值）。注意：余额低于此值时**不会自动划扣**（进入逾期），测试/小额经济服务器请调小或设 0 |
| 存款日利率 | 0.0001 | 活期存款日利率（0.01%/天 ≈ 年化 3.65%）；利息从准备金池支出。**有硬上限护栏**：不得超过最便宜贷款方案的套利上界（超出自动钳制 + 日志警告，见第三节） |
| 额度增长冷却时长（小时） | 24 | 成交后此时间内不计入额度（0 = 关闭） |
| 同对交易检测窗口（天）/ 上限（笔） | 30 / 3 | 防互买对刷的窗口与笔数（见第六节） |
| `ipDebtLimit` | 100000 | 同 IP 欠款上限（见第六节）。建议 ≥ 额度上限的 1~3 倍；宿舍/网吧型服务器调大防误伤；0 = 关闭 |
| 逾期制裁三档天数 | 7 / 14 / 30 | 手续费翻倍 / 冻结 / 坏账的天数门槛 |

> 所有金融配置**热改即时生效**（新贷款按新配置，存量贷款用创建时的利率快照）；唯一例外仍是货币后端（与市场相同，需重启）。

## 九、服主运营工具

- **全部借款历史**（喵喵银行右下，仅 OP）：全服借贷流水，每行显示借款人最近 IP（排查小号）；「坏账」页签一键筛出所有坏账；坏账行「撤销」按钮（5 秒冷静期确认弹窗）
- **`/market loan clear <玩家>`**：命令版坏账撤销（与界面按钮双入口）
- **管理面板告警行**：准备金池当前值 + 坏账总额；准备金为负（= 服主负债）整行红色告警
- **审计账本**：`config/cobblemarket/credit/` 下 `loan_records_<日期>_<语言>.csv` + `repayment_records_<日期>_<语言>.csv`，中英双份按天分文件、只追加；还款明细含本金/利息拆分与方式（主动/自动/结清）
- **已还清贷款自动清理**：结清 90 天后从状态删除（审计 CSV 永久保留），防存档膨胀

## 十、常见问题

### 玩家余额足够却不自动扣款？

`autoRepayMinBalance` 保底：划扣后余额不得低于该值，余额 ≤ 保底时不会划扣（进逾期）。小额经济服务器把保底调小或设 0。

### 玩家借过一次就再也借不了？

额度 = 信用基础 − 欠款全额。借 100 后额度立刻减 100，还清才恢复——这是信用卡模型的设计行为。若服主设了额度下限，下限只保底「无欠款」玩家。

### 玩家买了东西额度却没涨？

三个常见原因：① 刚成交，还在**额度增长冷却**期内（默认 24 小时，0 关闭）；② 与同一卖家成交已超**同对交易上限**（默认 3 笔）；③ 有未结清贷款（借钱期间买入不计额）。另外额度下限保底会淹没小额增量。

### 存款利息什么时候结算？

查看存款界面/存取款时实时计算（本金 × 日利率 × 完整天数），存取操作把已累积利息落账入本金；不足整天不计息。

### 同 IP 的玩家互相连累？

`ipDebtLimit` 按「30 天内用过该 IP 的玩家欠款总和」聚合。宿舍/网吧等 NAT 共用 IP 的环境请把上限调到额度上限的 3 倍以上，或设 0 关闭。

### 坏账后玩家怎么办？

玩家交易被冻结、永久禁借。服主两档干预：封禁管理界面解封（恢复交易，仍禁借）；或撤销坏账（交易+借款全恢复，审计账本保留撤销事件）。

### 玩家借钱存进银行吃利息，会刷钱吗？

不会。**存贷利率护栏**（见第三节）保证存款日利率有硬上限（自动钳制，超出部分直接截断并记日志），任何「借款 → 存款 → 还款」组合下利息差 ≤ 0，套利无收益。默认值 0.0001 距默认方案套利上界有 4.8 倍余量。

### 卡片申请的「存款余额要求」怎么算？

按**净存款**判定：净存款 = 活期存款余额 − 未还欠款（不含已注销坏账）。借钱充存款无法满足门槛——借款直接冲减净存款；申请界面显示的条件值就是净存款。

### 如何验证系统工作正常？

- 借款 → 每期到期前一天黄色提醒 → 到期自动划扣（余额足）或逾期红通知（余额不足）
- 逾期 7/14/30 天逐级制裁；还款后实时降档
- 管理面板看准备金池与坏账总额；审计 CSV 对账

## 十一、安全与信任边界

- 准备金池记账**从不凭空产生货币**：借款出账、还款回池、坏账只标记（池子已出账）
- 坏账 = 服主认亏（玩家拿走的钱不还）；池子为负 = 服主负债，管理面板红色告警
- IP 类防刷挡的是「顺手开小号」，挡不住挂代理的专业攻击者；额度公式（新号零额度、交易额背书）+ 额度增长冷却 + 制裁链是主要防线
- 组团对刷套现被三层压制：交易额成本（刷 1 万额度要真实成交 2 万）、同对交易检测（抬成本）、额度增长冷却（堵快进快出）——有耐心的长线养号仍难完全封死，额度上限就是服主的风险敞口旋钮
- 关闭总开关只拦**新增**借贷，已有贷款照常运行——与市场总开关「只拦新交易不卡资产」同哲学
