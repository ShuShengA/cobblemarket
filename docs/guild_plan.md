# 市场商会（轻商会）计划

> 状态：已拍板，待排期（2026-08-31）
> 定位：市场模组的**社交维度** + 运营钩子——从单人交易走向群体组织；周榜竞争驱动交易活跃度，服主可围绕商会做活动。

## 一期范围（轻商会）

### 组织本体

- 玩家可创建商会（名字 + 从**服主预置图标库**选 Logo）、加入、退出；成员列表界面可查看
- Logo：贴图文件夹由服主自行添加，玩家创建时从预置里选；不支持玩家自定义上传
- 创建成本可配（默认 10,000），防垃圾商会刷屏
- 人数上限可配（默认 20）；退出后 **7 天冷却**才能创建/加入新商会——防「成交前入会蹭免费、成交后退会」
- 数据存 PersistentState（与市场数据同库），PersistHelper 兜崩溃

### 会内交易费率特权

- **精灵市场/物品市场直购**成交时，买卖双方同商会 → **卖家**手续费按会内费率计算（可配：全免 0 / 减半，服主定；默认减半）
- 拍卖（多人竞价无明确对手方）与求购单（先交付后确认）一期不适用，二期再议
- **会内减免的交易不计入金融信用额度统计**——与「借贷来源交易不计额」同一防刷名单（见 docs 金融系统计划），防互刷额度
- 减免幅度不叠加其他折扣；特权文案须写清「卖家省手续费」，避免玩家误以为买家省

### 周榜竞争

- 每周统计各商会**全口径成交额**（直购+拍卖+求购，与全服累计成交额同口径），仅展示与称号，不影响任何费率
- 排名第一的商会获「市场霸主」称号，全服广播；称号展示于成员名牌/界面（形式实现时定，走既有颜色模板）

## 明确不做（原大方案砍掉的部分）

- **共享仓库**：自由存取是纠纷重灾区（被偷/跑路），需权限+限额+审计才成立——不做
- **价格战**：机制未想清（谁降？强制还是自愿？套利空间大）——不做
- **独立内部市场**：会抽干主市场流动性，且与金融防刷冲突最深——二期按玩家反馈再议

## 配置（`guild` 段）

- 开关、创建成本、人数上限、会内费率（0/50%）、退出冷却天数、周榜结算时间
- 热重载级（改费率即时生效无状态约束）

## 排期与工作量

- 排在金融系统（1.1.0）与市场天气之后：1.2.0 候选主力
- 工作量约为金融系统的一半（组织本体 + 成交判定 + 周榜统计；无仓库/内部市场等重头）
- 模组规矩照旧：E 键白名单、颜色模板、中英 CHANGELOG 同步、设置弹窗加项配分割线
