# 求购单系统测试流程（beta.6）

> 环境：双账号（A=买家，B=卖家），单机切换账号登入同一存档即可；无需专用服务器。

## 一、创建求购单

- [ ] 入口：市场入口界面右下角求购单图标按钮（悬停显示名称）→ 求购单界面
- [ ] 界面布局：返回按钮（右缩 17px/顶 10px）、余额（左上）、tab（全部求购|我的求购）、「+」发布按钮，均不压背景边框
- [ ] 发布精灵单：
  - [ ] 物种输入：中文名 / 英文名 / 资源 ID 三种均能解析出预览；留空 = 任意精灵
  - [ ] 闪光三态按钮循环（不限→★→☆），预览同步变色
  - [ ] 形态按钮（多形态物种如洛托姆）：展开列表选择后**预览 3D 模型变化**；第一项「全部形态」
  - [ ] 特性选择：物种解析后列出该物种全部特性；**第一项固定「不限」可回选**
  - [ ] 性格选择：25 种列表滚动；**第一项固定「不限」**（不参与滚动）
  - [ ] IV 六项输入（留空=不限）、价格区间、备注（100 字上限）
  - [ ] 冻结提示显示 maxPrice；余额不足发布失败红字
- [ ] 发布物品单：
  - [ ] 物品输入模糊搜索（中文名/ID）、多匹配列表点选（金色高亮）
  - [ ] 件数/价格/备注；冻结提示 = max × 件数
- [ ] 发布成功：行显示正确——图标（3D 精灵/物品）、名称属性色、条件徽章（★/☆）、买家头像、剩余时间、价格缩写（≥1 万 k/M/B，悬停显示完整值）、行按钮；精灵单**不显示 ×1**

## 二、卖家交付

- [ ] B 对精灵单点「交付」→ 弹窗（订单摘要+买家留言+「选择精灵」按钮+成交单价预填 minPrice）
- [ ] 「选择精灵」→ 选择界面标题「选择要交付的精灵」、价格框隐藏、「选择此精灵」按钮；返回按钮回求购单
- [ ] 选精灵后自动回交付弹窗：按钮显示所选精灵名、下方 ✓符合要求/✗不符合要求
- [ ] 不匹配精灵：✗ 显示 + 点确认红字提示「该精灵不符合求购要求」
- [ ] 未选精灵点确认：红字「尚未选择精灵」；价格超区间：红字
- [ ] 物品单交付：件数/单价输入（显示背包持有量、预填 min(剩余,背包)）
- [ ] 提交成功：提示「等待买家确认」；行金色「待确认」；数量+价格隐藏
- [ ] **锁定**：B 已提交后其他卖家再交付被服务端拒绝（行按钮灰「待确认」）
- [ ] 交付后精灵从卖家队伍/PC 移除

## 三、买家确认

- [ ] A 收到通知（在线聊天框；离线上线补发，见第五节）
- [ ] 行按钮变「处理交付」→ 确认弹窗：**完整精灵信息**（名字★Lv+公母图标/属性/性格+特性/携带物/IVs 六行彩色/卖家/价格）+ 拒绝原因输入框（选填）
- [ ] 物品单确认弹窗：物品名 ×N + 卖家 + 出价
- [ ] **接受**，核对结算：
  - [ ] A 冻结金扣实际价，差价（max−price）进 A 待领余额
  - [ ] B 收款 = price − 中介费（fee = price × buyOrderFeePercent，向上取整）
  - [ ] 货进 A 待领取（精灵回队伍/物品回背包）
  - [ ] 精灵单直接关单（列表消失）；物品单 remaining 扣减，凑满关单
  - [ ] 交易历史有记录（正确类别/金额/手续费）
- [ ] **拒绝+留言**：B 聊天框「您交付给 A 的 X 已被退回。留言：xxx」；货进 B 待领取；订单保持 OPEN 可再交付
- [ ] 拒绝无留言：B 收到无留言版通知

## 四、资金边界

- [ ] 发布时冻结 = maxPrice × 数量（精灵 ×1）核对余额变化
- [ ] 物品部分交付：接受 m 件后退差价 m×(max−price)，remaining 同步减
- [ ] 买家主动关单：退剩余冻结金；**有 pending 时先退悬空货给卖家再退款**
- [ ] 订单过期（buyOrderExpiryDays）：pending 货退卖家、冻结金退买家、全服广播移除
- [ ] **服务器重启**：重启后 pending 悬空货不丢，买家仍能确认/拒绝
- [ ] 余额显示：≥10 亿时余额/待领余额显示 B 单位（如 1.5B），以下原样千分位

## 五、离线通知

- [ ] 求购单各通知（交付提交/接受/拒绝/过期）收信人离线 → 上线后补发（语言渲染正确、颜色正确）
- [ ] 同玩家超 10 条时丢最旧
- [ ] 市场/拍卖离线通知抽查：挂单被买走、出价被超、流拍、强制下架
- [ ] 补发消息为历史快照（不重复、不遗漏）

## 六、治理校验

- [ ] 封禁账号：发布/交付/接受被拦（红字）；**关闭求购单允许**（取回冻结金）
- [ ] 精灵黑名单：被拉黑的精灵交付被拒（红字）
- [ ] 物品黑名单/蛋交易开关：对应交付被拒
- [ ] 携带物黑名单：携带被拉黑物品的精灵交付被拒

## 七、UI 回归

- [ ] 弹窗观感：打开时下层行信息透出压暗（市场同款）；精灵 3D 压暗、球种/携带物/物品图标隐藏；关闭恢复
- [ ] 三个弹窗（创建/交付/确认）互斥打开、ESC/取消正常、resize 保存输入与选择状态
- [ ] 行内无元素重叠（价格/时间/头像/待确认标记）；悬停面板信息完整无重复标签
- [ ] 性别图标：所有精灵详情界面（市场/拍卖/管理/待领取/确认弹窗）第一行均有且与文字底部对齐
- [ ] 配置升级：旧配置（无 buyOrder 字段）启动日志出现「Config missing fields detected」，新字段以默认值落盘、旧设置保留

## 八、并发/性能（可选）

- [ ] 20+ 求购单下列表滚动流畅
- [ ] 两卖家同时向同一单交付：一个成功后另一个被锁定拒绝
- [ ] 买家确认与订单过期同时发生：无重复结算/丢货
