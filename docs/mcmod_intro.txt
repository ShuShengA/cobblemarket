CobbleMarket —— 面向 Cobblemon 服务器的玩家交易市场

════════════════════════════════════════

CobbleMarket 是一个为 Cobblemon 开发的玩家间交易市场模组（Fabric）。
玩家可以自由上架队伍或 PC 中的宝可梦、背包中的物品，供全服玩家浏览、筛选与购买；
支持上架手续费、挂单过期自动返还、卖家待收款、封禁与黑名单治理、交易历史审计等一整套市场机制。

本模组目前处于测试（Beta）阶段，功能已完整可用，但可能存在未知问题，
建议先在测试服验证后再投入正式服务器。

- 对应 Minecraft 版本：1.21.1（Fabric）
- 前置：Fabric API、Fabric Language Kotlin、Cobblemon ≥ 1.7.0
- 可选：CobbleDollars / Cobblemon Economy（虚拟货币）、Cobblemon Smartphone（手机 App 入口）
- 开源协议：MIT

一、打开市场

有三种方式进入市场：

- 快捷键 K：默认按键，可在 游戏设置 → 按键绑定 → "打开市场" 中修改
- 命令：输入 /market gui
- Cobblemon Smartphone：若服务器安装了智能手机模组，市场入口会自动出现在手机 App 列表中

二、市场入口界面

打开市场后首先看到入口界面，提供以下入口按钮：

- 精灵市场：进入宝可梦交易市场
- 物品市场：进入物品交易市场
- 交易历史：查看自己的交易记录
- 管理员面板：仅 OP（权限等级 ≥ 2）可见

三、精灵市场主界面

精灵市场是所有玩家浏览、搜索、购买宝可梦的地方。
主界面按分页展示全服活跃挂单，点击"▼ 筛选"可展开完整筛选面板。

3.1 筛选面板

支持以下筛选条件（可任意组合）：

- 名称搜索：输入宝可梦名称或 ID 模糊匹配
- 闪光开关：只显示闪光宝可梦
- 性别：不限 / 公 / 母
- 属性：按属性（第一属性或第二属性）筛选
- 个体值（IV）：六项个体值（HP/攻击/防御/特攻/特防/速度）分别精确匹配，留空不判定
- 排序：价格 ↑ / 价格 ↓ / 等级 ↑ / 等级 ↓ / 最新
- [我的]：只看自己的挂单

将鼠标悬停在任一挂单上，可查看该宝可梦的完整信息：
属性、球种、性格、特性、个体值、携带物、卖家与价格。

3.3 购买

点击挂单上的"购买"按钮进入确认界面，展示宝可梦的等级与价格，
确认后直接扣款并放入你的队伍（队伍满时自动转入 PC）。

⭕截图：购买确认界面⭕

3.4 待收款与过期返还

主界面顶部显示你的"待收款"余额，点击"收款"一键领取。
挂单过期后进入"过期返还"列表，点击可一键取回
（队伍/PC 满时剩余部分保留，腾出空间后可继续领取）。

四、上架宝可梦

点击主界面"上架"进入选择界面：

- 顶部固定显示队伍中的宝可梦（标记 [队]），下方分页加载 PC 中的宝可梦（标记 [PC]）
- 支持搜索、按闪光/属性过滤
- 选中宝可梦后输入价格，确认即上架
- 上架时收取可配置的手续费（默认 5%）
- 挂单默认 14 天后过期（可配置），过期自动进入返还列表，不会丢失
- 队伍中至少保留一只宝可梦
- 同时上架数量受配置上限限制（默认不限）

五、物品市场

物品市场与精灵市场机制一致，支持：

- 按名称搜索物品
- 任意数量购买：买家可选择购买数量（不超过挂单库存），买走一部分后挂单继续在售
- 库存售卖：一次上架可卖多个同种物品（如 64 个钻石），买家分批买走
- 下架返还：卖家随时下架，物品返还背包

六、过期返还

挂单过期后不会丢失，而是进入你的"过期返还"列表：

- 精灵挂单：一键领取，宝可梦回到队伍（满则进 PC）
- 物品挂单：一键领取，物品回到背包
- 支持部分领取：空间不足时领取能放下的一部分，剩余保留
- 返还保留期默认 30 天（可配置，0 = 永不清理），超期未领取的返还将被永久删除，请及时领取

八、管理员面板（仅 OP）

权限等级 ≥ 2 的玩家在入口界面可看到"管理员面板"，包含：

- 所有已上架精灵：浏览并强制下架任意玩家的精灵挂单（支持按卖家搜索）

- 封禁管理：封禁/解封玩家交易（详见第九节）
- 全部交易历史：全服交易审计
- 精灵黑名单 / 物品黑名单：治理违禁物种/物品（详见第十节）

九、封禁系统

管理员可通过命令或管理面板封禁玩家参与交易：

- 命令：/market ban <玩家> [时长] [理由]
  时长格式如 7d（7 天）、12h（12 小时）、30m（30 分钟），可组合（如 1d12h）；不带时长 = 永久
- 解封：/market unban <玩家>
- 封禁列表：/market banlist
- 封禁只禁止交易（上架、购买），不冻结资产：
  被封禁玩家仍可下架自己的挂单、领取过期返还、收取待收款

十、黑名单系统

黑名单用于禁止违禁物种/物品进入市场，添加后立即生效（已上架的存量挂单也无法被购买）。

10.1 精灵黑名单

支持按以下维度组合限制：

- 物种：输入精灵名或 ID
- 个体值：六项 IV 可选填，留空不判定
- 形态：全部形态 / 默认形态 / 指定形态（如阿罗拉、伽勒尔、洗翠、帕底亚、四季形态等）

十一、命令列表

/market gui                           打开市场入口界面
/market ban <玩家>                    永久封禁玩家交易（仅 OP）
/market ban <玩家> <时长>             限时封禁，如 7d / 12h / 30m

/market unban <玩家>                  解封玩家
/market banlist                       查看封禁列表

十二、配置

配置文件：config/cobblemarket.json（首次启动自动生成）

currency.cobblemonEconomy      自动      优先使用 Cobblemon Economy 货币 API（检测到该模组时自动启用；cobeco 内置桥接可路由到 CobbleDollars/Impactor，服主在 cobeco 配置里设置 main_currency 后与 CobbleDollars 共享同一余额）
currency.cobecoCurrency         POKE     cobeco 结算货币：POKE=PokeDollars，PCO=PokeCoins（仅 cobblemonEconomy=true 时生效）
currency.cobbledollars          自动      使用 CobbleDollars 货币（检测到该模组时自动启用；cobblemonEconomy=true 时被忽略）
currency.item                   minecraft:diamond   物品货币 ID（未使用上述虚拟货币时生效）
pokemonListingFeePercent        5.0       精灵上架手续费百分比（0 = 免手续费）
itemListingFeePercent           5.0       物品上架手续费百分比（0 = 免手续费）
maxPokemonListingsPerPlayer     0         每玩家同时活跃精灵挂单上限（0 = 不限）
maxItemListingsPerPlayer        0         每玩家同时活跃物品挂单上限（0 = 不限）
listingDurationDays             14        挂单过期天数
pendingReturnRetentionDays      30        过期返还保留天数；超期未领取将被永久删除（0 = 永不清理）

十三、经济系统说明

- 货币：默认以钻石为货币，服主可配置为任意物品；安装了虚拟货币模组时自动切换（优先级：Cobblemon Economy → CobbleDollars），无背包空间问题
- 手续费：卖家上架时扣除（百分比），买家用标价购买
- 待收款：卖出收益先进入卖家的"待收款"，由卖家主动领取；
  领取时背包满也不丢钱——剩余部分保留在账本，清空背包后继续领取
- 离线收益：离线期间的卖出收益会在下次登录时提示领取
- 防吞钱兜底：任何退款、找零失败（背包满等极端情况）都会转入待收款账本，玩家的钱永远不会凭空消失

────────────────────────────────────────

十四、数据安全

市场数据（挂单、余额、历史）保存在 world/data/cobblemarket*.dat。模组内置存档自愈机制：

- 启动自动校验：每次开服校验数据文件完整性，损坏时自动从 .bak 备份恢复（仅丢失上次备份后的增量）
- 损坏文件保留：若无备份可用，损坏文件保留为 .dat.corrupt 供人工修复，服务器以空数据启动
- 日志提示：日志中出现 restored from backup（已恢复）或 preserved as .corrupt（需人工处理）时请留意

十五、常见问题

Q：购买提示"队伍和 PC 都已满"？
A：先腾出队伍/PC 空间再购买；若已扣款则款项会自动退还或转入待收款，不会损失。

Q：玩家被封禁了还能拿回挂单吗？
A：可以。封禁只限制交易（上架、购买），下架、领取返还、收取余额均不受影响。

Q：物品市场能一次买一部分吗？
A：可以。买家选择购买数量，买走部分后挂单剩余库存继续在售。

Q：如何防止玩家上架违禁内容？
A：使用管理员面板的黑名单功能：精灵黑名单支持物种+IV+形态组合限制，
   物品黑名单按物品 ID 限制，添加后立即生效（含存量挂单）。

Q：交易记录能保存多久？
A：游戏内保留最近 200 条记录；CSV 文件日志按日期归档于 config/cobblemarket/history/，长期保存。
