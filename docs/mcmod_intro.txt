CobbleMarket —— 面向 Cobblemon 服务器的玩家交易市场

════════════════════════════════════════

CobbleMarket 是一个为 Cobblemon 开发的玩家间交易市场模组（Fabric 与 NeoForge 双平台）。
玩家可以自由买卖队伍或 PC 中的宝可梦、背包中的物品——市场直购、拍卖、求购三条交易渠道并存，
并配套上架手续费、挂单过期自动返还、卖家待收款、封禁与黑名单治理、价格限制、交易历史审计等一整套市场机制；
另有一个可选的「喵喵银行」金融系统（信用借贷 / 分期偿还 / 存款 / 卡片凭证）。

- 对应 Minecraft 版本：1.21.1（Fabric / NeoForge 双平台）
- 前置：Cobblemon（1.8 及以上）；Fabric 另需 Fabric API 与 Fabric Language Kotlin，NeoForge 另需 Kotlin for Forge（不需要 Architectury）
- 可选：CobbleDollars / Cobblemon Economy / Impactor（虚拟货币）、Cobblemon Smartphone（手机 App 入口）
- 开源协议：GPL-3.0

完整功能列表与历次改动见模组自带的更新日志（CHANGELOG）。

一、打开市场

有三种方式进入市场：

- 快捷键 K：默认按键，可在 游戏设置 → 按键绑定 → "打开市场" 中修改
- 命令：输入 /market gui
- Cobblemon Smartphone：若服务器安装了智能手机模组，市场入口会自动出现在手机 App 列表中

二、市场入口界面

入口界面集中了市场系统的全部入口：

- 精灵市场 / 物品市场：两条主交易渠道
- 交易历史：查看自己的交易记录
- 拍卖场 / 求购单：底部两角的独立入口
- 喵喵银行：金融系统入口（服主开启后才可用）
- 管理员面板：拥有管理权限的玩家可见（OP 默认拥有全部管理权限）
- 设置：玩家自己的客户端设置

三、精灵市场

精灵市场是所有玩家浏览、搜索、购买宝可梦的地方。
主界面按分页展示全服活跃挂单，可展开筛选面板，按名称、闪光、性别、属性、个体值（IV）等条件筛选与排序，
也可以只看自己的挂单。

3.1 挂单悬浮详情

鼠标悬停在任一挂单上，可查看该宝可梦的完整信息：
属性、球种、性格、特性、个体值、携带物、卖家与价格等。

3.2 购买

点击挂单上的"购买"按钮进入确认界面，确认后直接扣款并放入你的队伍（队伍满时自动转入 PC）。

3.3 待收款

主界面顶部显示你的"待收款"余额，点击即可一键领取。
卖出收益不会因为背包满而丢失，详见第十五节"经济系统说明"。

四、上架宝可梦

点击主界面"上架"进入选择界面：

- 队伍中的宝可梦固定显示在最上方，PC 中的宝可梦分页加载，支持搜索与过滤
- 选中宝可梦后输入价格，确认即上架
- 上架时收取可配置的手续费
- 挂单在可配置的天数后过期，过期自动进入返还列表，不会丢失
- 队伍中至少保留一只宝可梦；同时上架数量受配置上限限制

五、物品市场

物品市场与精灵市场机制一致：

- 按名称搜索物品（也可按物品 ID 与完整词条搜索；附魔书、招式学习器这类有变体的物品可精确定位到具体变体）
- 任意数量购买：买家选择购买数量，买走一部分后挂单的剩余库存继续在售
- 库存售卖：一次上架可卖一整组同种物品
- 下架返还：卖家随时下架，物品返还背包

六、拍卖场

以竞拍的方式出售宝可梦或物品：

- 卖家设定起拍价与拍卖时长，全服玩家自由出价
- 倒计时结束后自动结算给最高出价者，货款进入卖家的"待收款"
- 支持"我的"页签查看自己发布的拍卖；流拍与强制下架的物品会自动返还，不会丢失
- 起拍价、加价幅度、拍卖时长等参数可由服主配置

七、求购单

发布自己的需求，让其他玩家来交付：

- 支持宝可梦与物品两类求购，可填写留言说明具体的要求
- 发布时冻结报酬，交付确认后支付给交付者
- 物品求购可附加组件要求（如只收带特定附魔的物品），不满足要求的交付会被拒绝
- 支持验收、关闭与强制下架，冻结的报酬会原路退还

八、过期返还

挂单过期后不会丢失，而是进入你的"过期返还"列表：

- 精灵挂单：一键领取，宝可梦回到队伍（满则进 PC）
- 物品挂单：一键领取，物品回到背包
- 支持部分领取：空间不足时领取能放下的一部分，剩余保留
- 返还保留期可配置；超期未领取的返还将被永久删除，请及时领取

九、交易历史与审计

- 游戏内历史界面：记录上架 / 卖出 / 买入 / 下架 / 退还等事件，可查看自己的记录

十、喵喵银行（可选金融系统）

金融系统**默认关闭**，由服主在配置中开启；开启后入口界面会出现"喵喵银行"：

- 信用借贷：可用额度按玩家的历史交易额自动计算，借款即时到账，按分期方案偿还
- 存款：闲钱存入银行按日计息，形成存贷闭环
- 还款柜台：查看未结清的借款，可逐期偿还或提前结清
- 逾期管理：到期自动划扣，余额不足则进入逾期并受到相应限制，还清后自动恢复
- 卡片凭证：喵·紫金卡 / 喵·黑金卡——高额度凭证，额度与手续费减免按卡种计算

金融系统的全部参数在独立的"喵喵银行配置"界面集中编辑；服主手册见模组附带文档。

十一、管理工具

管理员面板集中了全部管理功能：

- 所有已上架的精灵 / 物品：浏览并强制下架任意玩家的挂单（支持按卖家搜索）
- 拍卖场 / 求购单管理：查看全部拍卖与求购单，可强制下架
- 封禁管理：封禁或解封玩家交易。封禁只限制交易（上架、购买），**不冻结资产**——被封禁玩家仍可下架自己的挂单、领取返还与收取待收款
- 精灵黑名单 / 物品黑名单：禁止违禁物种与物品进入市场。精灵支持物种 + 个体值 + 形态的组合限制；物品精确到变体（如只禁某个附魔等级的书）；添加后立即生效，已上架的存量挂单同样无法被购买
- 价格限制：为指定物品设定价格上下限，防止恶意标价
- 服务器配置：手续费、挂单上限、时长、开关等全部可在游戏内编辑
- 全部交易历史：全服交易审计

十三、命令列表

/market gui                    打开市场入口界面
/market on | /market off       开启 / 关闭整个市场（紧急总开关）
/market ban <玩家> [时长] [理由]   封禁玩家交易（时长如 7d / 12h / 30m，可组合；不填 = 永久）
/market unban <玩家>           解封玩家
/market banlist                查看封禁列表
/market card                   管理卡片凭证（发放 / 收回 / 查看）
/market loan clear             撤销某玩家的坏账
/market reload                 应用配置文件的修改、免重启（货币配置仍需重启）

管理类命令默认仅 OP 可用；在游戏内输入 /market 可查看完整用法。

十四、配置

配置文件：config/cobblemarket.json（首次启动自动生成）。
绝大部分设置可以直接在游戏内修改：

- "服务器配置"界面（管理员面板底部）：手续费、挂单上限与时长、返还保留期、拍卖与求购参数、市场总开关等
- "喵喵银行配置"界面（从服务器配置界面进入）：金融系统的全部参数

手动编辑文件同样有效，改完用 /market reload 免重启生效。

十五、经济系统说明

- 货币：默认使用物品货币（默认为钻石，可配置为任意物品）；安装虚拟货币模组后可使用虚拟货币——Cobblemon Economy（仅 Fabric）、CobbleDollars 或 Impactor，无背包空间问题
- 手续费：卖家上架时扣除（百分比），买家用标价购买
- 待收款：卖出收益先进入卖家的"待收款"，由卖家主动领取；
  领取时背包满也不丢钱——剩余部分保留在账本，腾出空间后继续领取
- 离线收益：离线期间的收益会在下次登录时提示领取
- 防吞钱兜底：任何退款、找零失败（背包满等极端情况）都会转入待收款账本，玩家的钱永远不会凭空消失

────────────────────────────────────────

十六、数据安全

市场数据（挂单、余额、历史）保存在 world/data/cobblemarket*.dat。模组内置存档自愈机制：

- 启动自动校验：每次开服校验数据文件完整性，损坏时自动从 .bak 备份恢复（仅丢失上次备份后的增量）
- 损坏文件保留：若无备份可用，损坏文件保留为 .dat.corrupt 供人工修复，服务器以空数据启动
- 日志提示：日志中出现 restored from backup（已恢复）或 preserved as .corrupt（需人工处理）时请留意

十七、常见问题

Q：购买提示"队伍和 PC 都已满"？
A：先腾出队伍/PC 空间再购买；若已扣款则款项会自动退还或转入待收款，不会损失。

Q：玩家被封禁了还能拿回挂单吗？
A：可以。封禁只限制交易（上架、购买），下架、领取返还、收取余额均不受影响。

Q：物品市场能一次买一部分吗？
A：可以。买家选择购买数量，买走部分后挂单的剩余库存继续在售。

Q：拍卖和求购的钱什么时候到账？
A：求购单在发布时冻结报酬，交付确认后立即支付给交付者；拍卖在倒计时结束、结算给最高出价者后进入卖家的待收款。

Q：金融系统默认是开的吗？
A：默认关闭，需要服主在配置中开启后，入口界面才会出现"喵喵银行"。

Q：如何防止玩家上架违禁内容？
A：使用管理员面板的黑名单与价格限制：精灵黑名单支持物种+个体值+形态的组合限制，物品黑名单与价格限制精确到物品变体，添加后立即生效（含存量挂单）。

Q：交易记录能保存多久？
A：游戏内保留最近的记录；CSV 账本按日期归档于 config/cobblemarket/ 下，长期保存。
