# 市场天气报告（品类热度指数）计划

> 状态：已拍板，待排期（2026-08-31）
> 定位：**氛围功能**（非交易决策工具）——让市场看起来「活着」，玩家每次进市场有动态内容可看；不期待影响玩家交易行为（玩家买精灵看 IV/性格/闪光/价格，不看「今天火系热不热」）。

## 目标

入口界面右侧新增「市场天气」背景板（风格照大木博士立绘），展示分组级别的热度标签（热门/平稳/冷门），数据来自市场自身成交统计。可选二期：连续热门触发全服广播 + 服主预设活动（该系交易所税减半）。

## 分组（第一版只做两组，映射表零维护）

| 分组 | 数据来源 | 说明 |
|---|---|---|
| 属性组 | species 自带 types（18 种） | 双属性精灵计入两个属性组 |
| 稀有度组 | species tags：legendary / mythical / pseudo_legendary | 传说/幻兽/准神 |

**明确不做**：「普通/稀有/史诗」自定义稀有度（宝可梦世界观无此概念，需维护名单）、「用途分组」（Showdown 使用率是外部数据、骑乘向非标准概念）。进化形态组（进化链数据 Cobblemon 有）列为二期可选。

## 热度判定

- 当日分组成交量 vs 昨日，涨 ≥10% → 热门（可配），跌 ≥10% → 冷门，其余 → 平稳
- **最小成交量门槛**：日成交 <5（可配）的组不参与标记，显示「数据不足」——防小服个位数成交噪声（3 单→4 单 = +33% 假热门）

## 数据源与统计

- 交易历史 CSV 已覆盖直购/拍卖/求购三渠道全量成交，分组统计直接重算即可（存量历史立即有效，不依赖功能上线后新数据）
- 每日定时统计一次（默认凌晨 3 点，可配），产出当天热度标签存 State，客户端进市场随 payload 下发
- 与「全服累计成交额」共用成交统计层（见 [[finance-plan]]）
- 与 CSV 重算的关系开工时拍板：CSV 重算（历史立即有效）vs State 累加（实时但需回填历史）

## 展示

- 入口界面右侧背景板（照大木博士样式），列出今日热度标签
- **emoji 不可用**（MC 默认字体渲染为豆腐块）→ 用贴图小图标代替（晴/多云/冷各一张，或按分组类型画图标）
- 颜色遵循模组既有模板：热门=金色、平稳=白色、冷门=灰蓝
- 无数据/数据不足显示灰色「—」

## 触发事件（二期可选）

- 某分组连续 3 天热门 → 全服广播：「🔥 市场动态：XX 系精灵连续 3 天热销！」
- 服主预设活动：该系交易所税率临时减半（自家费率配置，可行）
- **不做**：捕获率提升（Cobblemon 内部数据，无 API，hack 风险大）

## 配置（`marketWeather` 段）

- 阈值：热度涨跌百分比（默认 10%）、最小日成交量（默认 5）
- 统计时间点（默认 03:00）、广播开关、税率折扣活动开关与折扣值
- 全部热重载级（统计时读取即可，无启动级约束）

## 排期与工作量

- 排在金融系统（1.1.0 主线 8 批次）之后：1.1.0 后半段或独立 1.2.0
- 工作量约为金融系统的 1/4~1/3；大头是入口界面背景板 UI 与统计/分组代码，统计本身很小
- 模组规矩照旧：E 键白名单、设置弹窗加项配分割线、颜色模板、中英 CHANGELOG 同步
