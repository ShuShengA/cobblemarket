## 三、1.3.0 待搬运（发布 1.3.0 时逐项做）

- [ ] **新开 `points.md`（RP 系统）**，至少写清：
  - **RP 是什么**：本模组的**高级货币**，与主货币并行流通；**不可兑换、不可转让、不参与金融**
    （黑金卡 / 紫金卡的手续费与折扣只跟主货币有关）
  - ⚠ **RP 从哪来由服主决定** —— 别写成「充值货币」。任务奖励、充值、两者并用都行
  - **拿到 RP 的三条路及区别**（用户特别关心，讨论过两轮）：

    | 方式 | 谁生成 | 服务器存不存 | 能作废 / 列出 / 限次 / 绑定 |
    |---|---|---|---|
    | `/market points give` | 服主游戏内直接给 | —（直接到账） | — |
    | 本地码 `code create` | 服主游戏内生成 | **存表** | 全都能 |
    | 外部签名码（签名器 / 网站） | 服主在**服务器之外** | **不存**，只记已用 serial | 都不能 |

    **要点**：区别的本质是「**服务器认不认识这张码**」—— 外部码是让服务器**不需要认识也能验签**，
    两边零耦合（不开端口、不做内网穿透、网站挂了不影响游戏）。这是它存在的唯一理由。
  - **游戏内充值**（个人收款码模式）：模组不碰钱、**不假装能判断支付成功**；「我已支付」是**声明不是证据**，
    **宁可漏发不可滥发**
  - **换 RP 图**：走服务器资源包覆盖两张 png；给服主的说明要附**模板 zip**
  - 底稿：`docs/points_plan.md`（内部方案，写网站时对着它写）
