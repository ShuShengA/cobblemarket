# AI 审查修复冒烟测试清单

> 用途：AI 审查修复批次（限价溢出 / aspects 钳制 / itemIds Set 化 / 防重 / 输入保护等）的针对性回归测试。
> 全部改动均为「钳制/防重/溢出保护」性质，正常操作路径行为不变——按本清单冒烟即可，无需全量重测。

## 核心交易链（每次必跑）

- [ ] 上架一只精灵 → 市场上可见
- [ ] 小号购买该精灵 → 余额扣款、精灵到手
- [ ] 卖家领取待收款 → 余额到账
- [ ] 上架一件物品 → 购买 → 领取（物品链同上）

## 修复点针对性测试

- [ ] **价格限制**：设一条精灵限价（如 1000~5000）→ 低于/高于限价上架被拦截、区间内上架通过
- [ ] **黑名单/价格限制/求购单创建**（各一条，带形态选择）→ 正常创建成功（验证 aspects 上限 64 不误伤正常操作）
- [ ] **物品市场搜索**：搜索物品名（如「钻石」）→ 结果正确、翻页正常
- [ ] **拍卖创建**：点一次确认 → 正常创建并跳转拍卖场（防重标志）
- [ ] **出价弹窗（双账号）**：A、B 同开拍卖场 → A 出价 → B 的弹窗预填价更新；B 输入自己的金额后，A 再出价 → **B 的输入不被覆盖**
- [ ] **购买弹窗总价**：物品市场购买输入大数量（如 9999）→ 总价显示正常数字，无负数
- [ ] **管理端翻页**：连点上一页/下一页 → 按钮灰/亮状态正确、内容正确
- [ ] **封禁**：带理由封禁一名玩家 → 生效、理由正常显示（100 字内不受影响）

## 不用测的

- 余额超 9.2e17 显示截断（真实服务器不可能达到，未改）
- 玩家名建议节流（仅 OP 可用，信任边界内，未改）
- EXPIRED 条目存档滞留（仅冗余、无复制、不参与交易，未改）
- 渲染布局 / 动画 / 图标（本批未触碰）

## 测试环境标注

- 上述清单单机即可覆盖大部分；出价弹窗一条需双账号（单机开两个客户端连本地服务器，或专用服务器两个账号）
