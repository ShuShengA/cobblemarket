# 拍卖全息公告板计划

> 状态：已讨论定方向，待排期（2026-08-31）
> 定位：把市场「搬进游戏世界」的第一步——世界内全息展示层 + 现有 GUI 操作层混合。公告板负责「看」，聊天播报点击直达负责「操作」。

## 目标

服务器大厅/出生点放置一块世界内公告板，实时展示最新上架拍品（3D 展示 + 名字/价格/倒计时悬浮文字），与聊天拍卖播报联动（上架亮板、成交闪金）。客户端零安装（服务端原版机制）。

## 技术方案

### 实体选型（原版 Display 实体）

| 元素 | 实体 | 说明 |
|---|---|---|
| 拍品展示 | ItemDisplay | 精灵球/物品 3D 大模型，可缩放旋转 |
| 名字/价格/倒计时 | TextDisplay | billboard 模式面向玩家，金色金额 |

- 精灵 3D 本体展示（noAI 真精灵实体站台）为二期视觉升级，MVP 用球种物品
- 实体私有性注意：Display 实体全服可见，公告板是**公共展示**，不做私人界面

### 数据与实体组

- 每个拍品 = 一组实体（球 + 名字 + 价格 + 倒计时）
- 展示最新 3~5 个 ACTIVE 拍品，实体总数 15~20，性能零压力

### 刷新与动画

- 每 10 秒取 AuctionState 最新拍品，与现有实体组比对：新增→建实体、移除→删实体、变化→更新 Text（内容不变不发包）
- 旋转：ItemDisplay 变换 + 内插时长（服务端周期性设置目标角度，客户端平滑旋转，不逐 tick 发包）
- 成交时金色闪烁数秒（与聊天成交播报同事件源：settleAndBroadcast）

### 放置与持久化

- 指令（OP）：`/market hologram place` / `remove` / `list`
- 位置 + 实体 ID 存 PersistentState，重启恢复、防孤儿实体
- 配置：展示数量、刷新间隔

### 交互（二期）

- 一期纯展示；二期在公告板前放隐形 Interaction 实体，右键打开拍卖场 GUI

## 实施步骤（排期后执行）

1. `HologramBoardState`（PersistentState：位置 + 实体 ID）
2. 指令 3 条（place / remove / list）
3. 刷新任务（10 秒 tick，复用 AuctionState 数据）
4. 实体组同步器（创建 / 更新 / 移除）
5. 成交金色闪烁联动
6. 全部服务端代码（common main），双平台自动同步
7. 编译验证 + 服主测试（专用服务器：观察实体同步/重启恢复/多玩家视距）

## 待拍板项

- 公告板默认位置策略（指令放置即可，还是出生点自动生成？）
- 拍品排序（最新优先，同拍卖列表）
- 展示拍品数量默认值（建议 5）
- 是否需要服主开关（默认开）
