# 市场内嵌迷你牧场计划

> 状态：已讨论定方案（2026-08-31），待排期
> 定位：精灵市场界面左侧内嵌一块「草方块地面 + 栅栏围栏」的迷你牧场，当前页所有行精灵在草地上活动（walk 动画 + 随机游走）。是「精灵市场不再死气沉沉」的终极版——图标呼吸 → 牧场走路 → 购买飞升，动画叙事链完整。

## 已拍板的设计

- **行内精灵图标保留**（玩家直观感受优先，不可取消）
- **设置弹窗新增「牧场动画」开关**（默认开，玩家觉得卡可关）：
  - 开启：牧场精灵播放 walk 动画 + 在草地内随机游走
  - 关闭：牧场区显示**空草地**（只画背景，不渲染精灵模型）→ 模型总数回到现有的 14 个行图标，性能真正降下来
  - 布局不随开关跳变（面板固定加宽，牧场区常驻）
- **行 ↔ 精灵对应关系**：鼠标悬停行 → 牧场对应精灵跳一下/向前一步；悬停牧场精灵 → 对应行高亮（不解决对应关系，玩家不敢买）
- **购买飞升衔接**（二期）：确认购买 → 该精灵从牧场位置向上飞升出屏（约 0.5 秒加速曲线）→ 无缝衔接现有庆祝动画（从屏顶落下弹跳），形成「同一只精灵的连续旅程」

## 技术要点

- 精灵活动：`ground_walk` 动画（Cobblemon 现成）+ 每只精灵独立游走路径（随机目标点、转向、碰边回头）；待机时回落 idle（呼吸/眨眼）
- 草地+栅栏背景：GUI 贴图绘制（草方块地面 + 围栏美术图）
- 设置弹窗加行按既有规则：分割线数组 + done 下移 + DIALOG_H 加高
- 性能：一期完成后按老规矩满页开 F3 验证；开关是逃生阀

## 实施步骤（排期后执行）

1. 面板布局加宽 + 牧场背景绘制（贴图）
2. 牧场精灵状态管理（每行精灵：位置/朝向/动画相位/游走路径）
3. walk 动画接入（FloatingState + ActiveAnimation 或 pose 切换）
4. 行 ↔ 精灵双向悬停高亮
5. 设置弹窗「牧场动画」开关 + 词条
6. 购买飞升出屏 + 庆祝动画衔接（二期）
7. 满页 F3 性能验证
