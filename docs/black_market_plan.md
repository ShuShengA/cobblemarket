# 黑市系统计划

> 状态：方案已拍板（2026-09-05 讨论定稿），1.2.0 候选主题；**待 1.1.0（金融系统）彻底完善后开工**
> 定位：独立子系统，由服主单方面经营——为每个玩家独立生成的随机商店，每天自动刷新，不满意可付费强制刷新，所有内容由服主配置。

## 核心原则

- 每个玩家看到的内容不同（独立生成）
- 每天固定时间自动刷新（默认凌晨 3 点）
- 强制刷新付费递增（每天上限 3 次，可配置，并且可以配合紫金卡和黑金卡资质，比如拥有紫金卡可获得额外 1 次刷新机会，拥有黑金卡可获得额外 2 次刷新机会，这些也都可以配置）
- 全部内容服主配置

## 技术约定（实现前必读）

- **精灵 NBT 还原一律走 `util/PokemonLoader.fromNbt(registryManager, nbt)`**，勿手写 `Pokemon()`——Cobblemon 的实例方法 `loadFromNBT` 内部走 `copyFrom`，会丢掉 `isAlpha`（头目精灵永久变成普通体型，不可逆）。若本功能要缓存/还原精灵快照（例如当天商品固定），必守此条。
- 判断其他 Cobblemon API 是否安全：内部走 `CODEC.decode` 的安全（如 `Pokemon.clone()`），走 `copyFrom` 的要怀疑字段覆盖不全。

## 已拍板决策（2026-09-05）

1. **版本**：大版本内容，1.2.0 主题（1.1.0 金融系统之后）
2. **货币**：复用主市场货币后端（CurrencyHandler——CobbleDollars/Impactor/物品三套自动适应），不搞独立货币
3. **持久化**：沿用 PersistentState + .bak 模式（与 FinanceState 同款，防崩溃丢数据），**不做**文档草案里的每玩家 JSON 文件方案
4. **价格取整**：全程 Double 计算，最后 `Math.round` 四舍五入一次（不在中间步骤取整，防累计误差）；0V 时 = 基价本身无小数问题
5. **商品池条目类型**：`pokemon`（单只）+ `item`（物品）。**标签批量添加已砍**（2026-09-05 用户拍板）：精灵定价复杂（V 概率/倍率与稀有度强耦合），标签批量会把不同稀有度的精灵混进同一套价格配置，服主反而难定价——单只添加让每只精灵的价格配置一一对应；生成桶（bucket）同样不考虑
6. **黑市档位**：四档（普通/稀有/史诗/传说）是黑市自己的稀有度分层，由服主配置商品池决定

## 商品池

- 两个独立板块：精灵黑市 / 物品黑市
- 四档位：普通 / 稀有 / 史诗 / 传说（各自基价、IV 倍率、闪光倍数、每刷数量、权重池）
- **精灵添加 = 纯单只添加**（无标签批量）：搜索精灵 → 设置档位/权重/等级区间/V 概率/闪光配置（预填全局默认值，可改）→ 入池
- **暂存区加速**：搜索多只 → 依次加入「待添加栏」暂存 → 重复累积 → 对暂存区全体统一设置配置 → 批量入池（本质是多次单只搜索的累积，省重复配置）。暂存区为界面内存暂存（简单版），关闭管理界面清空并提示
- **已添加列表按档位筛选**：服主可按档位查看已有精灵及其配置（价格/权重等），后续添加时有参考、不会没头绪
- 每刷数量：普通 4 / 稀有 2 / 史诗 1 / 传说 1（可能为 0）

## 精灵属性规则

- 等级：服主配置固定（默认 15，服主也可设置等级区间，这里应该是两个配置项组合，比如：最低等级（大于等于1）和最高等级小于等于100，两个输入一样才是固定一个等级，且最低等级必须小于等于最高等级）
- **IV：V 数概率制**（V = 个体值 31 的项数，与价格限制同口径）——服主配置 0V-6V 七个概率权重（自动归一化，不必凑和）；生成时先按权重抽 V 数 → 随机选哪几项为 31 → 其余项随机 0-30（保证 V 数精确）
- **价格联动提醒**：V 数概率与价格公式耦合（价格 = 基价 × 倍率^V数），调高 V 概率 = 调高产出价格分布，服主配置时注意
- 闪光：概率制（可配置）
- 性格/特性/性别：随机

## 价格公式

```
精灵价格 = round( 基价 × 倍率^V数 × 闪光倍数 )
物品价格 = 基价（固定）
```

默认参数：普通 5/1.2/2.0、稀有 50/1.3/3.0、史诗 200/1.5/4.0、传说 10/1.2/5.0

## 每日刷新与强制刷新

- **商品生成时机**：每日刷新时按权重抽精灵 → 立即生成具体属性（V 概率/等级区间/闪光概率）→ 按公式定价——属性不生成就算不出价格，玩家看到的是「这只具体的精灵」
- **玩家可见属性**：黑市界面悬停商品显示等级/IV/闪光等详情（与主市场悬停体验一致），避免「买完发现 IV 稀烂」的差评
- **惰性刷新**：不做服务器定时批量刷——玩家打开黑市（含上线后首次打开）时检查「今天是否已刷」，跨天即重刷；效果等价于「每日 03:00 后看到新商品」，实现简单可靠
- **旧商品处理**：刷新即全部替换，未购买的旧商品消失、无补偿——每天刷新是规则
- 强制刷新：费用 = 基础费 × 倍率^(次数−1)，每日上限默认 3 次（可配置），紫卡持有者 +1 次、黑卡持有者 +2 次（可配置），每日自动刷新时次数归零
- 配置：enabled / base_cost / multiplier / max_per_day

## 购买规则

- 每玩家独立库存，购买后商品从该玩家列表移除，互不影响
- 交易流程：点击 → 检查商品还在+货币足够 → 确认购买 → 扣款发货 → 列表移除
- **转售不限制**：黑市买的精灵/物品可自由挂主市场/拍卖（不做来源标记，经济影响服主自行评估）

## 形态与入口

- **形态**：只卖默认形态，卖什么物种就是什么（不随机形态、不做进化链）
- **入口**：入口界面加「黑市」按钮，所有玩家可见，`enabled` 开关控制显隐；按钮具体位置开工时定（用户开工时会指定）
